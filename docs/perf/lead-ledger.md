# 8ppq lead ledger

Status: initial ledger, `hash-thing-8ppq.8`, 2026-05-02.

This is the shared judgment pin for the autonomous game-direction navigation epic (`hash-thing-8ppq`). It records the current hypothesis, next probe, falsifier, evidence, scores, blockers, and last navigation-review verdict for each active lead. The scores are coordination shorthand, not truth: `1` is weak/low, `5` is strong/high.

## Update rules

- Read the relevant row before claiming or closing an `8ppq` lead.
- Nav-reviews must update rows for every discussed lead when they apply verdict-to-bd actions.
- Claim/close comments should cite the row's current next probe or falsifier when relevant.
- If a row's blocker state disagrees with bd dependencies, bd wins; update this file in the same commit.
- New `8ppq` descendants get a row in the same change that files or first materially updates the bead.

## Review hooks

When a navigation review issues a verdict, update this file in the same patch:

| verdict | ledger update |
|---|---|
| continue | Update next probe/evidence if changed; leave scores unless evidence changed. |
| pivot | Replace hypothesis or next probe; note old direction in evidence. |
| kill / merge | Set status to closed and record the closing reason in falsifier/evidence. |
| promote / demote | Update tier/priority context and last verdict. |
| block / defer / unblock | Update open questions/blockers and status. |
| split | Add rows for new subleads and link parent row. |
| criteria-rewrite | Update falsifier and closure language to match the bead description. |
